# Skill: issue-chat-thread-history

## Intent

AIチャット履歴を「単発QA」ではなく「スレッド単位（QAQA...）」で保存し、履歴から再開可能にする。

## 前提

- 実装対象は AI ワークスペース。
- 保存基盤は Dexie（IndexedDB）。

## 用語定義

- **スレッド**: 同一会話コンテキストで継続されるメッセージ集合。
- **メッセージ**: `role`（user/assistant）と本文、時刻を持つ単位。
- **新規チャット**: 新しい `threadId` を発行して会話を開始する操作。

## 機能要件

1. 履歴ボタンを押すと、スレッド一覧を表示する。現在のサイトに紐づく必要はない。
2. 一覧項目は少なくとも `thread title(または先頭要約)`, `updatedAt`, `message count` を表示する。
3. スレッド項目をクリックすると、そのスレッドをアクティブにして会話の続きを開始できる。
4. スレッド再開時は過去メッセージをUIに復元し、次送信時に同一スレッドへ追記保存する。
5. 「新しいチャットを始める」ボタンを提供し、押下時は新規スレッドを作成して空状態から開始する。
6. スレッド未選択時の送信は、既定動作として新規スレッド作成にフォールバックする。
7. スレッドタイトルは、新規チャット開始時にAI生成

## データ要件

- `chatThreads` テーブルを最小単位として扱う。
- レコード例:
  - `threadId`
  - `siteId`
  - `title`
  - `messages[]`（`role`, `content`, `timestamp`）
  - `createdAt`
  - `updatedAt`
  - `messageCount`
- 主要インデックス: `siteId`, `updatedAt`。

## UI要件

- 履歴一覧は AI入力欄と競合しない位置に表示する。
- 現在アクティブなスレッドが視覚的に判別できる。
- 「新規チャット」操作は1クリックで到達できる。
- 履歴が空の場合の空状態メッセージを表示する。

## 受け入れ条件

- QA単位保存ではなく、スレッド単位で保存される。
- 履歴ボタンでスレッド一覧が表示される。
- 任意スレッド選択後、会話を続きから行える。
- 新規チャットボタンで新しいスレッドを開始できる。
- 再読込後もスレッド一覧と各スレッド内容を復元できる。

## 実装時注意（将来）

- 既存 `AI_ASK` フローに `activeThreadId` の概念を追加する。
- 既存の単発 `chat.save` 呼び出しは、`thread.create` / `thread.appendMessage` へ置換する。
- 既存機能との後方互換が必要なら、旧データをスレッドへ移行するマイグレーションを用意する。
